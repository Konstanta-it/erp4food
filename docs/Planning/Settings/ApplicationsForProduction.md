# Настройки обеспечения заявок на производство

**Настройки обеспечения заявок на производство** используются для заполнения настроек в АРМе ["Обеспечение заявок на производство"](../ApplicationsForProduction.md).

Справочник расположен в **"Настройках планирования"** - **"Настройки обеспечения заявок на производство"**.

[![1][1]][1]

В настройке указываются:

[![2][2]][2]

- *Наименование* - наименование настройки планирования;
- *Дата планирования* - дата планирования для подбора документа **"Заявка на производство"**;
- *Дата остатков* - дата для подбора остатков;
- *[Настройка формирования заявки](Planning/SettingsFormingApplicationsForProduction.md)* - настройка с товарными категориями для подбора документа **"Заявка на производство"**;
- *Вид заявки на производство (Производство, Упаковка и маркировка)* - вид заявки на производство для отбора. Из заявок с видом "Производство" подбирается продукция с типом номенклатуры *"Полуфабрикат", "Базовый продукт" и "Готовая продукция"*. Из заявок с видом "Упаковка и маркировка" подбирается продукция с типом номенклатуры *"Готовая продукция"*;
- *Объединять запуск в производственных заданиях* - флаг объединения запуска при сохранении производственных заданий. Если флаг установлен, то производственные задания будут формироваться в разрезе [рабочих центров](../../CommonInformation/WorkCenter.md) с суммированием количества одинаковой продукции. Основанием корневого производственного задания будет заявка на производство, все последующие задания сформируются на основании корневого задания. Если флаг не установлен, то для каждой производственной цепочки (от готовой продукции/полуфабриката/базового продукта до сырья) сформируются отдельные производственные задания без объединения количества одинаковой продукции;
- *Этап заявки на производство для чтения* - этап для чтения данных из документа **"Заявка на производство"**;
- *Этап заявки на перемещение для записи* - этап, в котором будут сохранены [заказы на перемещение](../../Warehouse/MovingProducts/TransferOrder.md);

- *Отборы, по которым будут подобраны потребности из заявок на производство*:
> - Склады выпуска;
> - Исключаемая номенклатура;
> - Товарные категории;
> - Производители.

*Если отборы не заполнены, то будет выведена вся потребность из заявок на производство.*

- *Описание* - описание для настройки планирования;
- *Автор*.
